# cartographer — example identity

`cartographer` is the **reference example identity**: a pure prompt + recipe data
package that turns a dataset and a question into a served interactive dashboard
with a written narrative. It exists to prove the pattern end-to-end — defined
entirely as data, loaded with zero `src/` changes.

See [`../README.md`](../README.md) for the data-only example-identity boundary
and the `identity.toml` schema.
