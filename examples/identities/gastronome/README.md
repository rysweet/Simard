# gastronome — example identity

`gastronome` is a worked example in the reference shape: a culinary menu- and
event-design identity that turns a menu brief and its constraints (headcount,
dietary needs, budget, service time) into a costed, nutrition-analyzed,
service-scaled menu with a prep schedule. Its four-stage recipe (compose →
nutrition & cost → scale → schedule) shows how a data-only identity drives real
domain rigor (a nutrition table, a costing roll-up, yield math, backward-from-service
scheduling) entirely from prompts and a recipe, with zero `src/` changes.

See [`../README.md`](../README.md) for the data-only example-identity boundary
and the `identity.toml` schema.
